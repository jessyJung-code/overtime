# 🌙 퇴근 대시보드 (Streamlit) — 여러 사람이 함께 쓰는 버전

누구나 앱 주소로 들어와 **이름 · 날짜 · 출근 · 퇴근**을 입력하면 구글 스프레드시트에 저장되고,
앱에 들어온 모든 사람이 같은 기록과 대시보드를 봅니다.

## 폴더 구성
```
app.py                  # 대시보드 앱
requirements.txt        # 필요한 패키지
secrets_예시.toml        # Streamlit Secrets에 붙여 넣을 설정 예시
.streamlit/config.toml  # 색상 테마
data/퇴근기록.csv        # 샘플 기록 (구글 시트 연결 전, 혼자 쓰는 모드에서 사용)
```

## 왜 구글 시트가 필요한가요?
Streamlit Community Cloud는 앱이 잠들었다 깨거나 재배포되면 앱 안의 파일이 처음 상태로 돌아갑니다.
그래서 여러 사람이 넣은 기록을 계속 보관하려면 바깥 저장소가 필요하고, 여기서는 구글 스프레드시트를 씁니다.
시트를 열면 모든 기록을 표로 직접 볼 수도 있어요.

## 설정 순서 (처음 한 번)

### 1. 구글 스프레드시트 만들기
- Google Drive에서 빈 스프레드시트를 하나 만들고 주소(URL, Uniform Resource Locator)를 복사해 둡니다.
- 탭은 앱이 처음 실행될 때 `퇴근기록` 이라는 이름으로 자동으로 만듭니다.

### 2. 구글 서비스 계정 만들기 (앱이 시트에 쓰기 위한 로봇 계정)
1. https://console.cloud.google.com 접속 → 위쪽에서 **새 프로젝트** 만들기
2. **API(Application Programming Interface) 및 서비스 → 라이브러리**에서
   **Google Sheets API**와 **Google Drive API**를 각각 검색해 **사용** 누르기
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**
   → 이름만 넣고 완료
4. 만든 서비스 계정 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON(JavaScript Object Notation)**
   → 키 파일이 내려받아집니다.
5. 키 파일 안의 `client_email` 주소(…@….iam.gserviceaccount.com)를 복사합니다.

### 3. 시트를 서비스 계정과 공유
- 1번 스프레드시트에서 **공유** → 5번의 `client_email` 주소를 **편집자**로 추가합니다.

### 4. Streamlit Cloud에 설정 넣기
- share.streamlit.io → 내 앱 오른쪽 **⋮ → Settings → Secrets**
- `secrets_예시.toml` 내용을 붙여 넣고, 시트 주소·관리자 비밀번호·JSON 키 값을 채운 뒤 **Save**
- JSON 키의 `private_key`는 `\n`이 들어간 한 줄 그대로 따옴표 안에 넣습니다.
- 사이드바에 **☁️ 구글 시트에 저장 중** 이 보이면 연결 성공입니다.

> ⚠️ JSON 키 파일과 실제 값을 채운 secrets는 **GitHub에 올리지 마세요.** 키가 있으면 누구나 시트를 고칠 수 있어요.

### 5. (선택) 기존 기록 옮기기
- 앱 사이드바 **엑셀/CSV(Comma-Separated Values) 불러오기**로 `data/퇴근기록.csv`나 예전 엑셀을 올리면 시트에 추가됩니다.
- 파일에 '이름' 열이 없으면 사이드바에 입력한 이름으로 저장돼요.

## 사용법
- **기록 추가**: 이름·날짜·출근·퇴근 입력 후 저장 → 바로 시트에 기록되고 화면이 바뀝니다.
  같은 사람이 같은 날짜를 다시 저장하면 그 줄만 새 값으로 바뀝니다.
- **보기**: `전체`를 고르면 사람별 비교 차트가 나오고, 이름을 고르면 그 사람 대시보드만 봅니다.
- **최신 기록 불러오기**: 다른 사람이 방금 넣은 기록을 바로 보고 싶을 때 누르세요. (가만히 있어도 20초마다 새로 읽어요)
- **개인 링크**: 앱 주소 뒤에 `?name=김세연`을 붙여 나눠 주면 이름 칸이 미리 채워집니다.
- **기록 수정·삭제**: 맨 아래 표에서. `admin_password`를 정해 두면 비밀번호를 아는 사람만 고칠 수 있어요.
  저장할 때 최신 시트를 다시 읽어서, 그 사이 다른 사람이 넣은 기록은 지우지 않습니다.
- 구글 시트에서 직접 고쳐도 됩니다. (날짜 `2026. 10. 26`, 시간 `오후 9:30:00` 같은 형식도 읽어요)

## 내 컴퓨터에서 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
- secrets가 없으면 `data/퇴근기록.csv`에 저장하는 **혼자 쓰는 모드**로 동작합니다.
- 내 컴퓨터에서도 구글 시트를 쓰려면 `.streamlit/secrets.toml` 파일을 만들어 `secrets_예시.toml` 내용을 채워 넣으세요.

## 야근 계산
- 근무시간 = 퇴근 − 출근 − 점심
- 야근시간 = 근무시간 − 정규근무 (0 미만이면 0)
- 자정을 넘긴 퇴근(예: 01:10)은 다음 날 새벽으로 계산합니다.
