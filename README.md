# 🌙 퇴근 대시보드 (Streamlit)

## 폴더 구성
```
toegeun_dashboard/
├─ app.py                 # 대시보드 앱
├─ requirements.txt       # 필요한 패키지
├─ .streamlit/config.toml # 색상 테마
└─ data/퇴근기록.csv       # 기록 데이터 (날짜, 출근, 퇴근)
```

## 내 컴퓨터에서 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
브라우저에서 http://localhost:8501 이 열립니다.

## Streamlit Community Cloud에 올리기
1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://share.streamlit.io 에서 GitHub로 로그인 → **Create app**
3. 저장소와 브랜치를 고르고 Main file path에 `app.py` 입력 → **Deploy**

## 사용법
- **왼쪽 사이드바 > 오늘 기록 추가**: 날짜·출근·퇴근을 넣고 저장하면 대시보드가 바로 바뀝니다.
- 같은 날짜를 다시 저장하면 덮어씁니다.
- **기준 설정**: 기본 출근, 점심, 정규근무, 늦은 퇴근 기준을 바꿀 수 있습니다.
- **엑셀/CSV 불러오기**: '날짜', '퇴근'(또는 '퇴근시간') 열이 있으면 읽습니다.
- **엑셀로 내려받기**: 현재 기록을 근무·야근시간까지 계산해서 엑셀로 저장합니다.
- 맨 아래 **기록 보기·수정**에서 표를 직접 고치거나 행을 지울 수 있습니다.

## 야근 계산
- 근무시간 = 퇴근 − 출근 − 점심
- 야근시간 = 근무시간 − 정규근무 (0 미만이면 0)
- 자정을 넘긴 퇴근(예: 01:10)은 다음 날 새벽으로 계산합니다.
